# CyberMonitor 硬件接线说明

## 1. 文档目标

本文件用于定义 CyberMonitor 的硬件连接关系、电源分配、GPIO 映射与保护器件安装方式，作为装配、排查与联调依据。

## 2. 系统组成

本系统包含以下硬件：

1. ESP32 开发板
2. LCD 2004 I2C 液晶屏
3. 8 个 3V 或 3.3V 机械直流电压表
4. 8 个续流二极管
5. 5V 2A 电源适配器

## 3. 电源连接

### 3.1 供电原则

1. 系统采用统一 5V 电源供电。
2. ESP32 从 `VIN` 或 `5V` 引脚取电。
3. LCD 从 `VCC` 引脚取电。
4. 所有模块共地。

### 3.2 电源接线关系

| 电源端 | 连接目标 |
| --- | --- |
| 5V 正极 | ESP32 `VIN` 或 `5V` |
| 5V 正极 | LCD `VCC` |
| GND 负极 | ESP32 `GND` |
| GND 负极 | LCD `GND` |
| GND 负极 | 8 个表盘负极公共地 |

## 4. LCD 接线

LCD 2004 使用 I2C 总线连接。

| ESP32 引脚 | LCD 引脚 | 说明 |
| --- | --- | --- |
| GPIO 21 | SDA | I2C 数据线 |
| GPIO 22 | SCL | I2C 时钟线 |
| 5V | VCC | 电源正极 |
| GND | GND | 电源地 |

## 5. 表盘接线

### 5.1 GPIO 分配

8 个表盘正极分别连接以下 ESP32 引脚：

| 通道 | 指标名称 | ESP32 GPIO |
| --- | --- | --- |
| CH0 | CPU Load | GPIO 13 |
| CH1 | CPU Temp | GPIO 14 |
| CH2 | GPU Load | GPIO 15 |
| CH3 | RAM Usage | GPIO 25 |
| CH4 | Net Up | GPIO 26 |
| CH5 | Net Down | GPIO 27 |
| CH6 | Disk Read | GPIO 32 |
| CH7 | Disk Write | GPIO 33 |

### 5.2 表盘极性连接

| 表盘端 | 连接方式 |
| --- | --- |
| 正极 | 对应 GPIO 输出 |
| 负极 | 系统公共 GND |

## 6. 续流二极管连接

### 6.1 安装目的

每个机械电压表内部为线圈负载。PWM 高频切换时，线圈会产生反向电动势。每路并联续流二极管，用于吸收反向电压，保护 ESP32 GPIO。

### 6.2 安装方式

每个表盘正负极之间并联一个二极管。

| 二极管端 | 连接位置 |
| --- | --- |
| 负极，带白环一端 | 表盘正极 |
| 正极 | 表盘负极 |

### 6.3 器件建议

1. 1N4148
2. 1N4007

## 7. 整体连接逻辑

### 7.1 连接关系概述

1. 电源 5V 输入 ESP32 与 LCD。
2. LCD 通过 I2C 接到 ESP32。
3. 8 路表盘正极分别接 8 个独立 GPIO。
4. 8 路表盘负极统一接地。
5. 每路表盘两端并联 1 个续流二极管。

### 7.2 拓扑结构说明

1. 主控负责输出 8 路 PWM 信号。
2. 每路 PWM 直接驱动一个机械表盘。
3. LCD 独立显示系统状态。
4. 所有外设与主控共享地参考。

## 8. 装配检查清单

### 8.1 上电前检查

1. 检查 5V 与 GND 没有接反。
2. 检查 LCD 的 SDA 与 SCL 没有接反。
3. 检查 8 路表盘正极全部接到正确 GPIO。
4. 检查 8 路表盘负极全部共地。
5. 检查 8 个二极管方向一致且正确。

### 8.2 通电后检查

1. ESP32 正常启动。
2. LCD 正常亮屏并显示内容。
3. 设备可以进入配网模式或运行模式。
4. 表盘在驱动输出后产生偏转响应。

## 9. 注意事项

1. 表盘满量程应为 3V 或 3.3V。
2. 所有 GND 必须共地。
3. GPIO 输出连接应与软件通道映射保持一致。
4. 二极管方向必须与文档定义一致。
5. 接线完成后再进行固件联调。
